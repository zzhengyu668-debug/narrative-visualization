# Wealth & Health: D3 Narrative Visualization

An interactive slideshow showing how global income and life expectancy changed from 1952 to 2007.

## Narrative design

- Three chronological scenes: 1952, 1982, and 2007
- Fixed annotations in every scene
- D3 transitions between scenes
- Country tooltips in every scene
- Continent exploration in the final scene
- Explicit state parameters and user-interface triggers

## Implementation

The visualization uses only HTML, CSS, JavaScript, and D3 v7. No other visualization or front-end library is used.

https://zzhengyu668-debug.github.io/narrative-visualization/

## Data

Gapminder country-year observations distributed through the Plotly datasets repository.
